# Análise Técnica de Aplicação Web — GitHub

Projeto acadêmico de análise de uma aplicação web moderna, com foco em arquitetura cliente-servidor, comunicação HTTP e observação de requisições pelo DevTools do navegador.

## Aplicação analisada

**GitHub**

## Objetivos

- Identificar responsabilidades do front-end e do back-end.
- Observar a comunicação cliente-servidor.
- Registrar requisições HTTP por meio da aba Network do DevTools.
- Documentar evidências técnicas obtidas durante a navegação.

## Evidências

As capturas reais do DevTools devem ser colocadas em `evidencias/network/`.

Sugestão de nomes:

- `01-network-fetch-xhr.png`
- `02-pesquisa-github.png`
- `03-request-headers.png`

> Importante: antes de publicar qualquer captura, verifique se não aparecem cookies, tokens, e-mails, chaves, dados pessoais ou outras informações sensíveis.
